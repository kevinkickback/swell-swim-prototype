# Swell Swim prototypes

[Open the prototype gallery](https://kevinkickback.github.io/swell-swim-prototype/)

Three admin dashboard concepts with shared synthetic operations data, plus four Black Friday swim lesson designs with sample prices, demo checkout, and printable vouchers.

## Run locally

Run the preview command with Node.js installed.

```sh
npm run preview:pages
```

Open the URL printed in the terminal.

## Edit and publish

Pages live in `public/prototypes/`. Update `public/index.html` and `public/assets/previews/` when adding or changing a gallery entry.

GitHub Actions deploys `public/` to GitHub Pages on pushes to `main`.
